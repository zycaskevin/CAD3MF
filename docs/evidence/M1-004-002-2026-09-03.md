## Provider decision

The first robust reconstruction adapter is `point-cloud-utils` using `make_mesh_watertight()`.

Selection constraints applied during M1-004-002:

- provider must be usable in a commercial CAD3MF product path;
- arbitrary broken triangle meshes must be accepted as reconstruction input;
- provider implementation must stay behind a replaceable worker boundary;
- backend success must never bypass CAD3MF topology/fidelity validation.

Current decision:

- `point-cloud-utils`: selected; current project/release path is MIT and exposes watertight reconstruction;
- PyMeshFix / MeshFix: not selected as default due GPL / commercial-license constraints;
- MeshLab / PyMeshLab: not selected as default due GPL distribution boundary;
- MeshLib: not selected as default under the reviewed non-commercial public license;
- Manifold3D: retained as a possible manifold kernel/certification tool, but not selected as the first arbitrary broken-mesh reconstruction provider.

## Shape-fidelity gate evidence

M1-004-002 implements geometry-preservation observations independent from provider success:

- bounding-box extent drift in mm;
- centroid drift in mm;
- deterministic sampled-vertex Chamfer distance in mm;
- deterministic sampled-vertex Hausdorff distance in mm.

The `sampled_vertex_*` metrics are point-set observations over deterministic vertex samples. They are not claimed to be continuous-surface Hausdorff/Chamfer measurements.

A deterministic distortion fixture scales a watertight mesh by 1.25x. Topology remains closed, but the result is rejected by the fidelity gate as `rejected_fidelity`.
