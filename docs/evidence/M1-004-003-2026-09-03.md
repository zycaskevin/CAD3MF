## Self-intersection implementation evidence

### Broad phase

CAD3MF computes per-triangle AABBs and uses a deterministic X-axis sweep. Candidate pairs must also overlap in Y/Z.

### Narrow phase

Backend: `python-fcl 0.7.0.11`.

The first implementation attempted `TriangleP` ↔ `TriangleP` collision. Native CI returned:

```text
collision function between node type 18 and node type 18 is not supported
```

The production implementation was corrected to represent each triangle as a one-triangle FCL `BVHModel` and use `BVHModel` ↔ `BVHModel` collision.

Final algorithm ID:

`sweep-aabb-plus-bvh-collision-with-topology-filter`

### Topological adjacency hardening

An early implementation skipped any candidate pair sharing a mesh vertex. Review identified a false-negative case: two faces may share a vertex/edge legally but intersect again elsewhere.

The final implementation therefore:

1. sends **every** overlapping AABB candidate through FCL;
2. treats any collision between non-adjacent faces as self-intersection;
3. for a pair sharing one vertex or one edge, computes the actual geometric triangle intersection;
4. accepts the contact only if it is confined to the shared vertex or shared edge;
5. detects additional coplanar or non-coplanar overlap as self-intersection.

This behavior is locked by native regressions.

## Thickness implementation evidence

Backend: `point-cloud-utils` `RayMeshIntersector` / Intel Embree.

Canonical method:

`inward_face_normal_chord`

Each triangle casts from a small epsilon inside the facet centroid along the inward facet normal. The first opposite-surface hit provides the local material chord.

PASS requires complete analyzed facet coverage, a valid inward hit for every analyzed facet, and an observed minimum >= the supplied millimeter threshold.

A discovered sub-threshold chord is an immediate FAIL. Partial no-violation coverage is `unknown`.

## Minimum-feature implementation evidence

Backend: PCU / Embree.

Canonical method:

`outward_opposing_surface_clearance`

Each facet casts outward. A hit counts as a negative-feature observation only when the hit normal opposes the source normal. The minimum observed opposing-surface clearance is compared to the supplied millimeter threshold.

This identifies negative features such as slots/gaps/channels. Positive thin members remain governed by minimum thickness.

The method is explicitly a discrete facet-normal observation, not a continuous arbitrary-angle clearance theorem.

## Topology prerequisite evidence

Thickness and feature analysis are blocked unless all are true:

- watertight
- zero non-manifold edges
- consistent winding

If those prerequisites are false, the ray backend is not invoked and the result is `unknown`.

Self-intersection remains independently analyzable on open/broken triangle soup.
