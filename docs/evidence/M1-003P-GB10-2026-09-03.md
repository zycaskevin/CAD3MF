## Deployment findings

The validated GB10 deployment exposed three upstream packaging issues that are now documented in the mesh-worker deployment guide:

1. `texture_baker` and `uv_unwrapper` setup import PyTorch during wheel preparation, so they require `pip --no-build-isolation` when using the prevalidated CUDA PyTorch environment.
2. `gpytoolbox` and `pynanoinstantmeshes` did not build cleanly on the validated aarch64 host.
3. SF3D imports those optional remesh dependencies at module import time even when `remesh=none`; CAD3MF therefore provides a compatibility patch that makes those imports lazy for the no-remesh production path.

No CPU or deterministic-mesh fallback was used for either benchmark.
