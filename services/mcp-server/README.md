# CAD3MF MCP Server

M0 MCP gateway for the CAD3MF deterministic geometry runtime.

## Contract

The server exposes six M0 tools:

- `create_design`
- `modify_design`
- `inspect_design`
- `render_design`
- `validate_design`
- `export_design`

`prepare_print` is intentionally not exposed until the slicing/Bambu runtime is implemented.

The server also exposes the canonical CAD-IR schema as the MCP resource:

`caddesk://schema/cad-ir/0.1`

The schema is generated by the Python `DesignDocument` model at runtime. There is no second hand-maintained TypeScript copy.

## Safety model

The MCP process never executes Python supplied by a user or model. `create_design` accepts JSON CAD-IR only. The document is passed to the Python worker, validated by Pydantic, compiled through the allowlisted CAD-IR compiler, checked by OpenCascade, and only then persisted.

M0 `modify_design` supports only `set_parameter`. Feature mutation operations remain closed until their invariants and revision semantics are tested.

## Persistence

Local MVP state is stored in SQLite through Node's built-in `node:sqlite` module:

- `projects` stores project metadata and the latest revision pointer.
- `revisions` stores immutable CAD-IR, validation, and artifact manifests.

Artifacts live under:

`$CAD3MF_DATA_DIR/projects/<project>/revisions/<revision>/`

Default data root: `.cad3mf-data`.

## Runtime

Requirements:

- Node.js >= 22.13
- Python 3.11
- CAD3MF Python dependencies from the repository root

Install and run:

```bash
cd services/mcp-server
npm install
CAD3MF_PYTHON=python npm start
```

The server uses stdio. Protocol data is written only to stdout; diagnostics go to stderr.

## Verification

```bash
npm run typecheck
CAD3MF_PYTHON=python npm test
```

The E2E test launches the real MCP server with the official MCP v2 client, reads the CAD-IR resource, creates the golden magnet module, modifies `magnet_diameter` from 6.2 to 8 mm, inspects/validates/renders/exports revision 2, restarts the MCP process, and verifies that SQLite persistence still resolves revision 2 as latest.
